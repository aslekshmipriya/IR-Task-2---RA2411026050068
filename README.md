# Text Classification Battle — Compare, Analyze and Defend

## Project Overview
This project compares four machine learning algorithms for text classification using TF-IDF feature extraction.

## Dataset
**20 Newsgroups Dataset**

Selected categories:
- Computer Graphics
- Baseball
- Space
- Politics

## Machine Learning Algorithms
1. Decision Tree
2. K-Nearest Neighbors (KNN)
3. Support Vector Machine (SVM)
4. Multinomial Naive Bayes

## Methodology
- Text preprocessing
- TF-IDF feature extraction
- Train-test split (80:20)
- Model training and prediction
- Performance evaluation
- Confusion matrix analysis
- Unigram versus unigram-and-bigram experiment

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- Macro F1-score

## Tools and Libraries
- Python
- Google Colab
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## Results
The original unigram experiment achieved an accuracy of approximately 90.48% with Multinomial Naive Bayes. The notebook contains the detailed results for all four models and the bigram experiment.

## How to Run
Open the Jupyter Notebook in Google Colab and run the cells from top to bottom.

## Project Files
The repository contains the notebook, evaluation results, and visualizations generated during the experiments.
